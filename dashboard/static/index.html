What is the Agent Factory?

The Agent Factory is a CLI tool that generates production-ready LangGraph agents from Jinja2 templates in under 30 minutes. Each generated agent includes structured logging, harness integration, retry logic, cost tracking, and audit trails — all the cross-cutting concerns that take days to hand-craft.

Pick a domain (retail, finance, healthcare, or HR), run one command, and get a fully compliant agent skeleton ready for business logic. A built-in compliance validator checks 8 golden-path requirements so nothing gets missed.
