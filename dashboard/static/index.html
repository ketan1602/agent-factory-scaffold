Each agent is described by a manifest: owner, tool grants, budget, approval rule and release thresholds. The factory generates the agent from the manifest, runs its live eval against an OpenAI-compatible model through agent-harness-core 1.5.1, applies the manifest's release gate, and records the cost. Every number on this page comes from the last release run.
