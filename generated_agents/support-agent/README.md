# support-agent

A support agent generated by agent-factory-scaffold. The scenario is the support agent from the
harness-foundations article: 16 cases, run with a live model through `agent-harness-core` 1.5.1.

## Setup

```bash
pip install "agent-harness-core @ git+https://github.com/ketan1602/agent-harness-core.git@v1.5.1"   # harness-core 1.5.1 from the GitHub tag
pip install -e .
cp .env.example .env   # then fill in LLM_API_KEY and LLM_BASE_URL
```

## Run the eval (live model)

```bash
python scripts/run_eval.py
```

Writes `measurements/eval_results.json`. Exit code 0 only when all 16 cases pass.
